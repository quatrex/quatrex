geometry_config#

Includes the geometry configuration classes.

Classes:

  • Box –

    An axis-aligned box defined by its minimum and maximum corners.

  • Cylinder –

    A solid cylinder.

  • Rectangle –

    A rectangular surface.

  • Tube –

    A cylindrical surface.

  • ShapeUnion –

    A union of multiple shapes.

  • ShapeDifference –

    A difference of two shapes.

  • VolumeProperties –

    Properties associated with a volumetric region.

  • SurfaceProperties –

    Properties associated with a surface region.

  • Region –

    Physical region in the geometry.

  • GeometryConfig –

    Final resolved geometry configuration for the device.

Functions:

  • parse_geometry_config –

    Parses the raw geometry config and resolves all shape references.

Rectangle #

Bases: BaseModel

A rectangular surface.

Needs a normal for orientation and a tangent vector to define the direction of the length and width. The rectangle is centered at the given center point.

Attributes:

  • center (list[float]) –

    The center point of the rectangle.

  • normal (list[float]) –

    The normal vector of the rectangle.

  • tangent (list[float]) –

    The tangent vector of the rectangle.

  • length (float) –

    The length of the rectangle along the tangent direction.

  • width (float) –

    The width of the rectangle.

center instance-attribute #

center: list[float]

The center point of the rectangle.

normal instance-attribute #

normal: list[float]

The normal vector of the rectangle.

tangent instance-attribute #

tangent: list[float]

The tangent vector of the rectangle.

The length of the rectangle is along the tangent direction and the width is along the cross product of the normal and tangent.

length instance-attribute #

length: float

The length of the rectangle along the tangent direction.

width instance-attribute #

width: float

The width of the rectangle.

The width is along the cross product of the normal and tangent.

Bases: BaseModel

Properties associated with a volumetric region.

Attributes:

  • epsilon_r (float | None) –

    The relative permittivity of the material in this region.

  • donor_concentration (float) –

    The donor concentration in this region in cm^-3.

  • acceptor_concentration (float) –

    The acceptor concentration in this region in cm^-3.

epsilon_r class-attribute instance-attribute #

epsilon_r: float | None = None

The relative permittivity of the material in this region.

This is used for solving the Poisson equation.

donor_concentration class-attribute instance-attribute #

donor_concentration: float = 0.0

The donor concentration in this region in cm^-3.

This is used for solving the Poisson equation and to determine the contact Fermi levels.

acceptor_concentration class-attribute instance-attribute #

acceptor_concentration: float = 0.0

The acceptor concentration in this region in cm^-3.

This is used for solving the Poisson equation and to determine the contact Fermi levels.

Region #

Bases: BaseModel

Physical region in the geometry.

This is the main model that gets used in the simulation, with all shape references resolved to actual shape definitions.

Attributes:

  • name (str) –

    A unique name for the region.

  • shape (Shape) –

    The geometry of the region.

  • properties (Any) –

    The properties associated with the region.

  • mesh_size (float | None) –

    The target mesh size for this region.

name instance-attribute #

name: str

A unique name for the region.

shape instance-attribute #

shape: Shape

The geometry of the region.

properties instance-attribute #

properties: Any

The properties associated with the region.

The type of the properties is determined by the shape of the region.

mesh_size class-attribute instance-attribute #

mesh_size: float | None = None

The target mesh size for this region.

This is an optional hint for the meshing process to control the local mesh density. If not provided, a default mesh size will be used.

Bases: BaseModel

Final resolved geometry configuration for the device.

Attributes:

  • regions (list[Region] | None) –

    The list of regions in the device geometry.

  • atoms_mesh_size (float | None) –

    The target mesh size for atomistic regions.

  • default_mesh_size (float) –

    The default target mesh size.

regions class-attribute instance-attribute #

regions: list[Region] | None = None

The list of regions in the device geometry.

atoms_mesh_size class-attribute instance-attribute #

atoms_mesh_size: float | None = None

The target mesh size for atomistic regions.

This is an optional hint for the meshing process to control the local mesh density in atomistic regions. If not provided, a default mesh size will be used.

default_mesh_size class-attribute instance-attribute #

default_mesh_size: float = 5.0

The default target mesh size.

Used for regions without a specified mesh size.
