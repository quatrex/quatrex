525class OBCConfig(BaseModel): 

526 r"""Options for open-boundary conditions (OBCs). 

527 

528 The OBC solvers compute the surface Green's functions of the 

529 contacts. The retarded surface Green's function satisfies the 

530 following recursion relation: 

531 

532 $$ 

533 \mathbf{g}^R = \left[\mathbf{m}_{0} - \mathbf{m}_{-1} \mathbf{g}^R 

534 \mathbf{m}_{+1} \right]^{-1}, 

535 $$ 

536 

537 where $\mathbf{m}_{0}$ is the contact Hamiltonian, 

538 $\mathbf{m}_{-1}$ is the coupling from the device to the contact, 

539 and $\mathbf{m}_{+1}$ is the coupling from the contact to the 

540 device. In the NEGF framework, the system matrix $\mathbf{m}$ 

541 includes scattering self-energies. 

542 

543 More information on the boundary conditions can be found in the user 

544 guide [section on open boundary conditions](../methodology/obc.md). 

545 

546 """ 

547 

548 model_config = ConfigDict(extra="forbid") 

549 

550 algorithm: Literal["sancho-rubio", "spectral"] = "spectral" 

551 """The algorithm to use when solving the OBC recursion relation. 

552 

553 - `"sancho-rubio"`: Uses the Sancho-Rubio iterative 

554 scheme[^sancho-rubio] to compute the surface Green's functions. 

555 This method achieves exponential convergence compared to the 

556 linear convergence of fixed-point iterations. 

557 

558 - `"spectral"`: Uses the specified `nevp_solver` to compute 

559 eigenpairs of the polynomial contact eigenvalue problem and uses 

560 them to construct the surface Green's functions. This is generally 

561 more efficient method when combined with a contour integral NEVP 

562 solver (`"beyn"`), but can require more parameter tuning. 

563 

564 [^sancho-rubio]: M. P. Lopez Sancho, et al., 1985 J. Phys. F: Met. 

565 Phys. 15 851, https://doi.org/10.1088/0305-4608/15/4/009 

566 

567 """ 

568 

569 nevp_solver: Literal["beyn", "full"] = "beyn" 

570 r"""The NEVP solver to use for the spectral OBC algorithm. 

571 

572 The contact eigenvalue problem is a polynomial eigenvalue problem of 

573 the form: 

574 

575 $$ 

576 \sum \limits_{n=-b}^{+b} \lambda^{n} \hat{\mathbf{m}}_{n} \mathbf{v} 

577 = 0, 

578 $$ 

579 

580 where $b$ is the number of [`block_sections`](#block_sections), and 

581 $\hat{\mathbf{m}}_{n}$ are potentially reduced coupling matrices. 

582 

583 From selected eigenvalues $\lambda = e^{i k}$ and eigenvectors 

584 $\mathbf{v}$, the surface Green's functions can be constructed. 

585 

586 - `"beyn"`: Uses the Beyn's contour integral method[^beyn] to solve 

587 the NEVP and find the eigenpairs within a specified contour in the 

588 complex plane. Also see the [`r_o`](#r_o), [`r_i`](#r_i), 

589 [`m_0`](#m_0), and [`num_quad_points`](#num_quad_points) 

590 parameters for configuration of the contour integral method. 

591 

592 - `"full"`: Uses a full dense eigensolver to solve for all 

593 eigenvalues, linearizing the original polynomial problem. This 

594 results in a doubled problem size which is also not reduced by 

595 block sectioning or exploiting periodicity. 

596 

597 !!! note 

598 Only used if [`algorithm`](#algorithm) is set to `"spectral"`. 

599 

600 [^beyn]: W.-J. Beyn, An integral method for solving nonlinear 

601 eigenvalue problems, Linear Algebra and its Applications, 2012, 

602 https://doi.org/10.1016/j.laa.2011.03.030. 

603 

604 """ 

605 

606 block_sections: PositiveInt = 1 

607 """The number of unit cell blocks along transport direction. 

608 

609 !!! note 

610 This is automatically determined in QTBM calculations. Thus it 

611 only has an effect in NEGF calculations. 

612 

613 In NEGF calculations, one needs to define block-sizes that lead to a 

614 block-tridiagonal tiling of the system matrix. These *transport 

615 blocks* are sometimes constructed from multiple unit cells. 

616 

617 With the [`block_sections`](#block_sections) parameter, one can 

618 specify how many unit cells are merged into a single transport 

619 block. This is then used when [`nevp_solver`](#nevp_solver) is set 

620 to `"beyn"` to reduce the size of the contact NEVP. 

621 

622 For example, if the transport cell is constructed from two unit 

623 cells along the transport direction, setting `block_sections = 2` 

624 will halve the size of the NEVP. The contact transport blocks need 

625 to be sorted accordingly. 

626 

627 """
